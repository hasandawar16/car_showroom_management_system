# car_showroom_management_system
🚗 Car Showroom Management System (Java)
📌 Project Overview

The Car Showroom Management System is a console-based Java application designed to manage showroom details, employees, and cars.
This project demonstrates the use of Object-Oriented Programming (OOP) concepts such as interfaces, inheritance, encapsulation, and arrays, along with user interaction through the console.

🛠️ Technologies Used

Java
OOP Concepts
Scanner Class for user input
Console-based Interface

✨ Features

Add and view Showroom details
Add and view Employee details
Add and view Car details
Menu-driven program for easy navigation
Uses interfaces for standard method implementation
Demonstrates inheritance and polymorphism

🧩 OOP Concepts Used

Interface (utility) for common methods
Inheritance (employee and car classes extend showroom)
Method Overriding
Encapsulation using class variables and methods
Arrays to store multiple objects

🎯 Learning Outcomes

Strong understanding of Java OOP fundamentals
Hands-on practice with interfaces and inheritance
Experience building menu-driven console applications
Improved logical thinking and program structuring

⚠️ Limitations

Uses fixed-size arrays (limit of 5 entries each)
Data is not stored permanently (no database)
Console-based UI only

🔮 Future Enhancements

Integrate MySQL database for data persistence
Implement dynamic data structures (ArrayList)
Add search and delete functionality
Build a GUI using Java Swing or JavaFX
